这家公司没有像往常那样堆参数、秀 benchmark，反而打了一张完全不同的牌——**价格**。按量付费每百万输出 token 只要 4.25 美元，还有个贡献者档直接把输出价格打到 0.2 美元，比 Claude Code 和 Codex 每月 20 美元的订阅费便宜了一个量级。

## 背景：Meta 为什么这时候下场

Muse Code 由 Meta AI 负责人 Alexandr Wang（亚历山大·王）主导推出。他执掌 Meta 超级智能实验室，负责基础模型研发，是扎克伯格重振 AI 战略时引入的核心人物。

发布时机很微妙。就在上周，Meta 因为偏弱的营收展望和下滑的自由现金流，股价单周跌了约 10%。市场一直在逼管理层证明：AI 基础设施烧了这么多钱，到底怎么赚回来。Muse Code 就是扎克伯格给 AI 业务找独立营收来源的最新尝试。

这个背景决定了 Muse Code 的产品策略：**不跟 Claude Code、Codex 拼谁的能力天花板更高，而是用价格撕开一个口子**。Wang 自己也说得直白——Meta 的产品在尖端能力上可能不是领先的，但成本优势非常明显。

另一个值得注意的点：Meta 自家的 AI 编程智能体走的是**协同开发**路线。Muse Spark 1.2 是和 Muse Code 一起开发、一起训练的，跟市面上"通用模型 + 套壳工具"的组合不一样，官方说这样搭配编程性能提升最明显。

## Muse Code 核心能力

和 Claude Code、Codex 类似，Muse Code 是一个终端编程智能体（terminal coding agent）。装好之后，它能直接在你的代码仓库里干活：

- **规划变更**：读代码库、理解现有架构，提出修改方案
- **编写代码**：按规划落地实现，改文件、加功能
- **验证结果**：跑测试、检查输出，确认改动没把东西弄坏
- **管理智能体**：在一个界面里同时调度多个 AI 驱动的数字智能体，覆盖软件开发全流程

Wang 的原话是"一条命令安装，然后处理各种用例下的完整软件工程任务"。对用过 Claude Code 的人来说，这套工作流一点都不陌生——本质上都是把"写代码"从手动变成委托给 AI。

Muse Code 目前以测试版（beta/preview）形式提供，Meta 员工已经在内部使用，后续会逐步扩大。

## 定价：真正拉开差距的地方

这是 Muse Code 最有杀伤力的一环。两档收费：

| 档位 | 输入价格（每百万 token） | 输出价格（每百万 token） | 条件 |
|:----|:---:|:---:|:----|
| **按量付费** | $1.25 | $4.25 | 无 |
| **贡献者档** | 约 $1.25 | **$0.20** | 同意数据用于改进模型 |

贡献者档的输出价格只有按量付费的二十分之一，官方说法是"比按量付费档便宜 10 倍以上"。代价是你选择以行业标准方式帮助改进模型——这跟所有编程智能体的做法一致，不是额外隐私让渡。

放到竞品里看更有感觉：

| 产品 | 订阅/计费方式 | 输出价格（每百万 token） |
|:----|:----|:---:|
| **Muse Code 按量档** | 纯按量 | $4.25 |
| **Muse Code 贡献者档** | 纯按量 | **$0.20** |
| Claude Code | $20/月订阅，超量转按量 | Sonnet 5: $10 / Opus 5: $25 |
| Codex | $20/月订阅，超量转按量 | GPT-5.6 Terra: $12 / Sol: $30 |

注意一个细节：Claude Code 和 Codex 的 $20 只是订阅门槛，用量超了之后按量价格是 10-30 美元每百万输出 token。也就是说，**重度用户一个月的 token 费用，可能比 Muse Code 贡献者档贵 50-150 倍**。对每天跑大量 agent 任务的开发者，这个差距是决定性的。

另外两个企业向的加分项：

- **零数据保留**：Meta 已开始接受申请，开发者数据不会被保留用于改进模型。Wang 称这是"对企业用户很重要的功能"——国内出海团队如果在意数据合规，这是个实打实的卖点。
- **OpenRouter 上架**：Muse Spark 1.2 会登陆 OpenRouter 平台，意味着可以和其他模型在同一个市场里比价、切换。

## 接入教程：怎么开始用

Muse Code 与 Muse Spark 模型 API 共用 Meta 开发者页面，目前测试版开放注册。大致流程：

**1. 注册开发者账号**

前往 Meta 开发者平台（developers.facebook.com 的 AI 相关入口，或通过 Muse Spark 模型页面进入），用 Meta 账号登录，创建应用获取 API Key。

**2. 安装 Muse Code CLI**

终端里执行一条安装命令（具体命令以官方文档为准）：

```bash
# 示例：通过 npm 全局安装
npm install -g muse-code

# 或者通过官方安装脚本
curl -fsSL https://get.muse.dev | bash
```

**3. 配置 API Key**

把注册时拿到的 Key 配置到环境变量：

```bash
export MUSE_API_KEY=你的API密钥
```

**4. 在项目里启动**

```bash
cd 你的项目目录
muse
```

之后就可以用自然语言描述任务：规划变更、写代码、跑测试。交互方式和 Claude Code 基本一致——AI 会在终端里给出计划，确认后执行。

**5. 选择贡献者档（可选）**

如果在意成本，在设置里切换到贡献者档（Contributor tier），输出价格降到 $0.20/百万 token。前提是接受数据用于模型改进。

> 定价以官网实时显示为准。测试版期间功能边界可能调整，生产环境大规模使用前建议先小流量验证。

## 适合谁用

**强烈推荐尝试：**
- **预算敏感的独立开发者**——想用 AI 编程智能体但觉得 $20/月订阅 + 按量超支太贵，贡献者档几乎零成本起步
- **跑批量任务的团队**——agent 跑得多、token 消耗大，按量 $4.25 或贡献者 $0.20 的价格优势巨大
- **想低成本验证 AI 编程流程的新手**——先花几块钱跑通"规划→编码→验证"闭环，再决定要不要升级到高端方案

**可以观望：**
- 追求极限能力的重度用户——复杂架构改造、大型代码库重构，现阶段 Claude Code / Codex 更稳
- 已有成熟订阅不想折腾的人——$20/月用惯了没必要立刻切换

**务实建议：** 主力用 Claude Code / Codex 做复杂任务，把 Muse Code 贡献者档当批量处理的省钱通道，两边各取所长。工具不是信仰，成本才是。

## FAQ

**Q：Muse Code 和 Muse Image 是什么关系？**
A：都是 Meta 超级智能实验室的 Muse 系列产品，但完全不是一回事。Muse Image 是 7 月发布的免费 AI 图像生成器（集成 Instagram/WhatsApp），Muse Code 是 8 月发布的 AI 编程智能体，底层模型不同、用途不同。相关阅读：[Meta Muse Image 完全指南](/ai/meta-muse-image-guide-2026/)。

**Q：贡献者档的数据会被怎么用？**
A：用于改进模型，这是行业标准做法（所有编程智能体都有类似机制）。如果不想数据被用，用按量付费档，或者申请零数据保留。

**Q：零数据保留怎么申请？**
A：Meta 表示"正开始接受申请"，具体入口在开发者后台，企业用户优先。申请通过后，你的开发数据不会被保留用于模型改进。

**Q：Muse Code 现在能替代 Claude Code 吗？**
A：复杂任务不建议。它还是测试版，尖端能力和生态成熟度不如 Claude Code / Codex。但当补充方案、批量任务省钱通道，非常合适。

**Q：国内开发者能用吗？**
A：Meta 的服务需要稳定的国际网络环境才能顺畅访问（见下方推荐表）。代码功能本身不涉及区域限制，但注册、调用 API 的过程需要跨境网络支撑。

**Q：跟 Cursor、Windsurf 这类 IDE 工具有什么区别？**
A：Cursor/Windsurf 是"IDE 里的 AI 助手"，Muse Code 和 Claude Code 一样是"终端里的 AI 智能体"，能自己读仓库、改文件、跑命令。两者可以配合用，不冲突。
