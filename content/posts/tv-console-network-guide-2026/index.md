## 🍎 Apple TV配置（最推荐的电视方案）

Apple TV是**唯一能在设备上直接装代理客户端的电视设备**（tvOS 17+），体验最好。

### 方案A：Surge（推荐）

Surge for tvOS 是 Apple TV 上最成熟的代理客户端。

**配置步骤：**
1. App Store 搜索 Surge（¥328一次性购买）
2. 打开 Surge → 「从剪贴板导入配置」→ 复制机场订阅链接粘贴
3. 选择一个节点 → 开启代理开关
4. 确认右上角显示 VPN 图标

**注意点：**
- Surge on tvOS **不支持策略组**（规则组），只有简单的节点选择
- 导入复杂配置文件（含大量规则）时建议用 iPhone 版 Surge 编辑配置后再同步
- tvOS 17+ 支持 iCloud 同步配置——iPhone 配好自动同步到 Apple TV

### 方案B：Stash（更便宜的选择）

Stash 有 tvOS 版，订阅制（约¥50/年），支持完整的 Clash 规则语法。

**配置步骤：**
1. App Store 安装 Stash
2. 首次启动 → 「添加配置」→ 粘贴机场订阅链接
3. 支持策略组——可以把不同的流媒体走不同的节点
4. 开启「代理」开关

**小技巧：** 看 Disney+ 和 Netflix 需要不同的解锁节点？Stash 的规则组可以做到——Netflix 走新加坡节点、Disney+ 走美国节点、YouTube 走香港节点。Apple TV 上唯一的完整规则组客户端。

### 方案C：旁路由网关（不想花钱）

如果没有 Surge 或 Stash 的预算，或者不想在 Apple TV 上装额外软件，可以用旁路由方案（见下文「路由器/旁路由网关」部分），把 Apple TV 的网络出口指向旁路由即可。

## 📺 Android TV / 电视盒子配置

Android TV 和各类安卓盒子（小米盒子、当贝盒子、Nvidia Shield等）是配置最灵活的电视设备——直接装APK就行。

### 核心工具：Clash Meta for Android (CMFA)

这是安卓电视上最稳定的代理客户端，支持 Clash Meta 内核。

**安装步骤：**
1. **下载APK** — 在电视上打开浏览器或通过U盘传文件，下载 `clash-meta-android-x.x.x.apk`
   - 推荐从 GitHub Releases 下载 arm64-v8a 版本（大多数电视盒子的架构）
2. **安装** — 电视设置中开启「允许安装未知来源应用」
3. **启动** — 打开 CMFA → 「配置」→ 粘贴机场订阅链接
4. **选择节点** → 点「启动」

**关键设置（很多人卡在这步）：**
- 开启「自动启动」（这样电视开机后自动连接）
- 代理模式选「全局代理」（电视上不需要规则分流——所有流量走代理反而稳）
- WiFi网络选「公网代理」（不要选「仅代理」）

### 备选：v2rayNG（轻量选择）

电视盒子配置不高的话，v2rayNG 比 CMFA 更省资源，配置方法类似。

### 没有遥控器？用手机APP远程控制

CMFA 和 v2rayNG 都支持web管理面板——在手机浏览器输入电视上显示的IP:端口号就可以远程切换节点、开关代理。方便程度比用遥控器点来点去高很多。

## 🎮 PS5 / PS4 配置

游戏主机**不能装代理客户端**，必须靠路由器层面解决。这里分三种情况：

### 方案A：路由器已经配好了代理（最简单）

如果全屋路由器已经刷了 OpenWrt / Merlin 并配置了代理 → **PS5 插线上网就直接有加速效果**，什么都不用设。

### 方案B：旁路由网关（无需动主路由）

在已有网络里加一台旁路由（旧手机/树莓派/电视盒子刷OpenWrt），配好代理后，把PS5的网关指向旁路由的IP。

**配置步骤（PS5端）：**
1. PS5 → 设置 → 网络 → 设定互联网连接 → 自订
2. IP地址设定：自动
3. DNS设定：手动 → 主DNS填 `8.8.8.8` 或 `1.1.1.1`
4. **MTU设定：自动**
5. **代理服务器：不使用**
6. 返回后自动连接 → 如果配置正确就能连上

**旁路由端要做的：**
- 开启 DHCP 服务或固定 IP 绑定
- 代理模式选「全局」或「规则」均可（游戏主机最好全局，避免规则判断出错导致连不上）
- 确认代理节点到游戏服务器的延迟（选日本节点玩日服、选美国节点玩美服）

### 方案C：仅改DNS（半失效方案，但0成本）

PS5 → 设置 → 网络 → 设定互联网连接 → DNS设定改为手动：
- 主DNS推荐：`208.67.222.222`（OpenDNS 可解锁大部分地区限制）
- 备选：`1.1.1.1` / `8.8.8.8`

**能解决什么：** Netflix/Disney+ 的DNS封锁（部分地区对游戏主机的流媒体做了DNS阻断）、部分游戏的下载速度。
**解决不了什么：** 游戏联机延迟、完整的地理限制解除。

> 改DNS是**最低成本的方案**——不需要任何额外设备或配置就能改善部分网络问题。如果只是偶尔看看Netflix、基本不玩联机游戏，改DNS就够了。要打联机游戏（COD、Apex、堡垒之夜），必须上方案A或B。

## 🎮 Xbox Series X/S 配置

Xbox和PS的配置逻辑基本一样——不能装客户端，靠路由器或旁路由解决。

### 最佳方案：路由器代理

方法同PS5。Xbox的网络设置路径：
1. 设置 → 常规 → 网络设置 → 高级设置 → DNS设定 → 手动
2. 网关指向旁路由IP

### Xbox专属技巧：用PC当代理网关

如果家中有台常开电脑（Windows 10/11），可以把它变成Xbox的代理服务器：

1. **Windows端** — 安装 Clash Verge / v2rayN，开启「允许局域网连接」
2. **Xbox端** — 设置 → 网络 → 高级设置 → 代理服务器 → 填PC的内网IP和端口（默认7890）

这个方法不需要额外硬件，但PC必须保持开机状态。

### Xbox的下载加速

Xbox游戏动辄100GB，下载速度比延迟更让人头疼：
- 在 Windows 代理软件的「规则模式」下把 `download.xbox.com` 和 `assets.xboxlive.com` 走直连（不经过代理，用本地宽带全速下载）
- 如果宽带本身慢，选日本/香港节点下载——有些代理节点对微软CDN有加速效果

## 📦 任天堂 Switch 配置

Switch 配置最简单——**直接在WiFi设置里填代理信息就行**（和手机/电脑一样）。

**配置步骤：**
1. Switch → 设置 → 互联网 → 互联网设置 → 选择当前WiFi → 更改设置
2. 「代理服务器设定」→ 开启
3. 填代理服务器地址和端口（和Clash/Stash等客户端的局域网代理端口一致，通常是 `192.168.x.x:7890`）
4. 保存 → 重新连接

**注意：**
- Switch只支持 HTTP 代理（SOCKS5需要路由器层面解决）
- 改代理后 eShop 地区识别会变——日服节点进日服eShop、美服节点进美服eShop
- 下载游戏时建议关代理直连（Switch的下载经常走CDN，代理反而慢）

## 📺 智能电视（Samsung/LG/Hisense等）的无奈选择

智能电视的系统（Tizen/webOS/VIDAA等）**不支持安装代理客户端**，也不能改WiFi代理设置（少部分LG电视例外）。可选方案：

### 方案A：路由器级别代理（唯一彻底的方案）

智能电视 → 全屋路由器已配好代理 → 电视自动走代理。这是最省心的方案——你什么都不用设置，电视开机即可。

### 方案B：改DNS

如果只是看Netflix/Disney+觉得卡或打不开，可以试改DNS：
- 电视 → 网络设置 → WiFi设定 → DNS改为手动
- `8.8.8.8`（Google DNS，通用）
- `208.67.222.222`（OpenDNS，部分地区解锁效果好）

**能改善什么：** DNS解析的访问速度和部分地区的DNS封锁。
**解决不了什么：** 完整的网络加速（IP层面封锁改DNS无效）。

### 方案C：外接盒子

如果智能电视原生系统太难用→买个Apple TV/小米盒子/Shield TV外接。300-1000块的盒子在流媒体体验上吊打任何智能电视自带系统，配置方法见上文对应章节。

## ⚙️ 一图看懂：路由器/旁路由搭建（没有的话怎么办）

如果你家没有软路由或旁路由，上面大部分方案都做不了。这里给两个最低成本的搭建方案：

### 方案一：旧手机变身旁路由（¥0）

需要一台闲置安卓手机（Android 8+），装 **Postern** 或 **DroidVPN**，开启「可路由模式」——手机连WiFi收到代理信号后，再以热点或USB网络共享的方式转发给电视/游戏机。

**性能：** 看4K流媒体够用（WiFi 5G频段下约50-80Mbps），打联机游戏不太稳。

### 方案二：树莓派/旧电脑当网关（¥0-200）

装 OpenWrt 或 Linux + clash 做旁路由，接主路由的LAN口。一台闲置的树莓派3B+就能跑2-3个设备看4K，¥100以内的二手N1盒子也行。

详细步骤太多不展开了，可以参考博客上的[全屋网络配置指南](https://huanghaiwan.com/posts/home-network-setup-guide-2026/)。

## ❓ 常见问题

### Q1：我只有一个机场订阅，能给电视和游戏机同时用吗？
当然可以。机场订阅在路由器/旁路由层面配置后，**所有连接该网络的设备共享流量**。手机的4G/5G用自己的客户端走手机流量，不冲突。

### Q2：Apple TV上Surge和Stash哪个好？
| 对比项 | Surge | Stash |
|:------|:-----|:------|
| 价格 | ¥328一次性 | ¥50/年订阅 |
| 规则组 | ❌ 不支持（仅简单节点选择） | ✅ 完整Clash规则 |
| iCloud同步 | ✅ | ✅ |
| 稳定性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 适合谁 | 追求稳定、不折腾 | 需要规则分流、性价比优先 |

一句话：预算够用 Surge，想省+需要规则分流用 Stash。

### Q3：游戏机联机延迟能降到多少？
取决于节点质量和游戏服务器位置。日本节点连日服APEX约30-60ms，美国节点连美服COD约120-180ms。**走IEPL/IPLC专线的节点比普通中转稳定50%以上。**

### Q4：配置了电视加速后，手机会受影响吗？
不会。如果在旁路由上配置代理——只有**网关指向该旁路由的设备**会走代理，手机和电脑的网关如果还是主路由，保持原样。
如果是全屋路由器方案——**所有设备都走代理**，手机上的代理APP建议关掉（避免双重代理）。

### Q5：Netflix/Disney+用电视看显示「代理检测」，怎么解决？
部分流媒体平台会检测代理IP并拦截。解决方案：
1. 选**原生IP节点**（很多机场的流媒体专用节点有原生IP，不会被检测）
2. 在规则里把 Netflix/Disney+ 域名走直连（如果你的机场有家宽/住宅IP节点的话）
3. 买支持流媒体解锁的机场——套餐上会标注「Netflix解锁」「Disney+解锁」

这个问题和配置方式无关，**取决于你的机场线路**。预算内优先选标注「原生IP」「流媒体解锁」的机场。

### Q6：电视/游戏机能看4K吗？
带宽要求（以一台设备看4K为例）：
- Netflix 4K HDR：约25Mbps
- Disney+ 4K：约20Mbps
- YouTube 4K：约30Mbps
- YouTube 4K 60fps：约40Mbps
- PS5/Xbox 联机游戏：约5-10Mbps（对延迟敏感，对带宽不敏感）

大部分机场香港/日本节点能跑到100Mbps以上，看4K完全没问题。

### Q7：Xbox和PS用一个机场，联机延迟谁更低？
实测**PS5的联机延迟略优于Xbox**（约10-20ms差距），因为PSN的服务器节点优化更好、接入点更多。但这个差距对大多数人感知不到。选节点质量好的机场，两台主机的联机体验都很稳定。

### Q8：Switch加速后能玩日服/美服的数字版游戏吗？
能。Switch锁区政策较宽松，改DNS或走代理后可以正常访问各区域eShop。需要注意的是：**账号所在地区决定了eShop显示的货币**（日服日元、美服美元、港服港币），代理切换节点也只能改变网络出口地区，不能改变账号归属地。
