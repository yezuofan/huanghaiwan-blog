## 太长不看版

很多人买完跨境网络加速服务，就只会打开 YouTube 看一眼"能不能看"，卡了就换节点，不卡就觉得还行。其实这样测出来的结论基本没用——白天不卡是应该的，真正考验线路的是晚上八点到十一点。

这篇指南把验收拆成 5 个动作，每个动作都有工具和合格线，照着做一遍，10 分钟就能判断这家值不值得续费：

| 检测项 | 用什么测 | 合格标准 |
|:------|:--------|:--------|
| 下载/上传速度 | Speedtest / fast.com | 下载 ≥ 带宽的 60% |
| 延迟（Ping） | 客户端节点延迟 / ping 命令 | 亚洲线路 < 80ms |
| 丢包率 | ping -c 100 | < 1% |
| 晚高峰表现 | 19:00-23:00 复测 | 速度不掉到白天的 1/3 以下 |
| 流媒体解锁 | 各平台实测 | Netflix/Disney+ 能看 4K |

## 为什么要自己测速验收？

服务商官网的测速图、评测文章里的速度截图，参考价值都不大。原因很简单：

**每个人家里到国际出口的物理距离不一样，运营商高峰期拥堵程度不一样，同一个节点在不同时间、不同地区表现可以差出好几倍。** 别人家的晚高峰 4K 流畅，不代表你家也是。

而且服务商的测速节点通常是最优的，跟你日常用的节点未必是同一个。真正有用的数据只有一种：**你自己在常用节点上、在晚高峰时段测出来的数字。**

这篇文章就是教你把这套数据测出来、看懂它。

## 测速前的准备

测速前先做三件事，不然数据没有参考意义：

**1. 关掉其它占用带宽的程序。** 下载任务、视频会议、系统更新全部暂停。特别是 Windows 后台更新和网盘同步，会把你测出来的速度吃掉一大半。

**2. 用有线连接。** 笔记本插网线，别用 Wi-Fi。Wi-Fi 信号衰减会让延迟凭空多出 20-50ms，你根本分不清是线路问题还是路由器问题。实在只能 Wi-Fi 的话，坐到路由器旁边测。

**3. 固定同一个节点和协议。** 测速期间不要切换节点。如果你用 Clash 这类客户端，把规则模式里的分流规则临时改成全局模式，确保流量真的走了被测节点，而不是走了直连。

## 核心指标一：下载与上传速度

下载速度决定了你能不能流畅看 4K 视频、下载大文件；上传速度影响直播推流和视频会议。

**工具：**

- **Speedtest（Ookla）**——最常用，选一个离你最近的测试服务器。注意：Speedtest 默认测的是直连速度，跨境线路需要手动选择服务器位置或者用客户端自带的测速功能
- **fast.com**——Netflix 出的，测的是到 Netflix 服务器的实际速度，看流媒体场景更真实
- **客户端自带测速**——Clash Verge、Stash、Shadowrocket 等客户端都有节点测速功能，测的是通过该节点的速度，最接近实际使用体验

**合格标准：**

| 你的宽带 | 跨境下载速度参考 |
|:--------|:--------------|
| 100M | ≥ 60Mbps |
| 300M | ≥ 150Mbps |
| 500M | ≥ 250Mbps |
| 1000M | ≥ 400Mbps |

注意：跨境线路不可能跑满你的宽带，因为国际出口带宽是共享的。速度能到本地带宽的 60% 以上就算健康，别拿 1000M 宽带要求线路跑出 900Mbps——那不符合物理规律。

## 核心指标二：延迟（Ping）

延迟是游戏玩家最关心的指标，也是很多人最容易误解的指标。

**延迟 = 数据包从你的设备到目标服务器再回来的时间**，单位是毫秒。延迟低不代表速度快，但延迟高一定体验差——尤其是游戏、视频会议这类实时交互场景。

**怎么测：**

- 客户端里一般会显示每个节点的延迟（Ping），这是到节点服务器的延迟，不是到目标网站的延迟
- 想测到具体网站的延迟，用命令行：`ping google.com` 或 `ping -c 10 1.1.1.1`
- 游戏玩家直接看游戏内的延迟显示最准

**合格标准（到节点）：**

| 线路类型 | 延迟参考 |
|:--------|:--------|
| 香港/日本/新加坡等亚洲节点 | 30-80ms |
| 美国西海岸节点 | 120-180ms |
| 欧洲节点 | 200-280ms |

如果亚洲节点延迟超过 100ms，要么是节点负载高，要么是线路绕路了，可以换一家试试。

## 核心指标三：丢包率

丢包率比延迟更能反映线路质量。**丢包 = 数据包在传输过程中丢失**，表现为视频画面卡顿、语音断断续续、游戏角色瞬移。

**怎么测：**

```bash
# Linux / macOS
ping -c 100 google.com

# Windows
ping -n 100 google.com
```

发 100 个包，看最后统计里的丢包百分比。ping 的目标换成你常用的网站或游戏服务器。

**合格标准：**

- 丢包率 < 1%：线路健康
- 丢包率 1%-3%：能用但体验一般，看视频偶尔卡一下
- 丢包率 > 3%：这条线路有问题，换节点或换服务

晚高峰丢包率会比白天高，这是正常的，但如果高峰期丢包超过 5%，基本可以断定这家线路在高峰期撑不住。

## 核心指标四：晚高峰专项测试

**这是最关键的验收动作，也是大多数人忽略的。**

跨境线路的拥堵集中在晚上 19:00-23:00，因为这段时间国内用户集中使用国际带宽。白天测速飞快、晚上卡成 PPT 的服务商，大有人在。

**测试方法：**

1. 白天（比如上午）测一次速度、延迟、丢包，记下数据
2. 晚上 20:30-22:00 之间，用**同一个节点**再测一遍
3. 对比两组数据

**合格标准：**

- 晚高峰速度 ≥ 白天速度的 60%：优秀
- 晚高峰速度是白天的 40%-60%：及格
- 晚高峰速度掉到白天 1/3 以下：这家线路高峰期撑不住，慎重续费

顺便说一句，很多服务商有"晚高峰保障"或者"高峰期不限速"的套餐说明，实测最能验证真假。

## 核心指标五：流媒体与 AI 工具解锁检测

对大多数用户来说，买跨境网络加速服务就是为了看 Netflix、Disney+，或者稳定使用 ChatGPT、Claude 这类 AI 工具。这一项单独测。

**怎么测：**

- **Netflix**：登录后搜索 "Test Patterns" 或直接打开任意剧集，能播放 4K 说明解锁了原生 IP；只能看自制剧说明是普通解锁；提示"您的网络有问题"说明没解锁
- **Disney+**：能打开并播放就说明解锁正常
- **ChatGPT / Claude**：登录后能正常对话即可，注意检查是否频繁弹 Access Denied 或验证码——这通常说明 IP 被风控了
- **TikTok**：能正常刷视频和发布，说明解锁了当地区域

**判断标准：**

| 平台 | 解锁正常的表现 |
|:----|:-------------|
| Netflix | 能看 4K 原生内容 |
| Disney+ | 能播放，不提示地区限制 |
| ChatGPT | 正常对话，不频繁弹验证码 |
| Claude | 正常登录使用 |
| TikTok | 能刷能发，区域正常 |

有些服务商明确标注"流媒体解锁"作为卖点，有些则不说。实测一遍最靠谱——毕竟不同节点的解锁情况可能不一样。

## 常见误区

**误区一：白天测速快 = 线路好。** 白天国际带宽闲置，是个线路都快。判断线路好坏必须看晚高峰。

**误区二：速度越快越好。** 对绝大多数人来说，看 4K 视频只需要 25Mbps 左右，打游戏更看重延迟和丢包。300M 宽带配一条稳定 60Mbps 的跨境线路，日常使用完全够。

**误区三：延迟低 = 不卡。** 延迟低但丢包高，一样会卡。两个指标要一起看。

**误区四：Speedtest 数字高 = 实际体验好。** Speedtest 测的是最优路径，实际访问某个网站走的是另一个路径。所以要在客户端里用常用节点实测。

**误区五：一次测速定终身。** 线路质量是动态的，今天好不代表下个月还好。建议每个月挑一个晚上复测一次，数据异常及时换。

## 常见问题 FAQ

**Q：测速需要多高的宽带？**
跨境线路速度受限于本地宽带和国际出口带宽。本地 100M 以上就能有不错的跨境体验，没必要为了"跑满速"去升级千兆。

**Q：为什么我的 Speedtest 直连很快，通过节点就很慢？**
Speedtest 默认测的是你到本地服务器的直连速度，根本没走跨境线路。要测跨境速度，要么在客户端里用节点测速功能，要么手动选一个海外的 Speedtest 服务器。

**Q：晚高峰速度掉多少算不正常？**
掉到白天的 1/3 以下算不正常。稳定在 60% 以上是优秀线路。这个标准同样适用于判断服务商宣传的"高峰期不限速"是否属实。

**Q：丢包率高一定是服务商的问题吗？**
不一定。本地网络（路由器老化、Wi-Fi 信号差）、运营商高峰期拥堵也会导致丢包。排查顺序：先换有线连接复测，再换节点复测，最后才怀疑服务商。

**Q：测出来不好怎么办？**
先换节点试试，同一家服务商的不同节点质量差异可能很大。换几个节点都不行，再考虑换服务商。这也是为什么建议准备两个不同线路的服务商做备份——一个主力一个备用，高峰期互相兜底。
